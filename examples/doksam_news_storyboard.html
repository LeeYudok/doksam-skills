General Rule

공통 규칙

레이아웃 · 그리드

  • 기준 해상도 360 x 640 (mdpi)
  • 좌우 안전 여백 16px 고정
  • 블록 간 수직 간격 16px

타이포그래피

  • 본문 14px / 행간 1.6
  • 제목 20px / 굵기 800
  • 메타 정보 11px / 색상 #888

컬러

  • Primary var(--accent) (이 예시는 기본값 #ea580c 사용)
  • Text #111 / Sub #888
  • Divider #eee

예외 처리

  • 로딩: 카드 스켈레톤 노출
  • 네트워크 오류: 상단 배너 "오프라인 상태입니다"
  • 빈 목록: 안내 문구 + 재시도 버튼

인터랙션

  • 목록 최상단에서 Pull-to-refresh 지원
  • 탭 전환은 좌우 스와이프 병행
  • 터치 영역 최소 44 x 44px

접근성

  • 본문 폰트 크기 OS 설정 연동
  • 다크 테마 지원
  • 모든 이미지에 대체 텍스트 제공
