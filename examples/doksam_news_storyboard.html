General Rule

2.1 Screen Definition (화면 정의)

기본적으로 모바일 앱 레이아웃을 따르며, 최상단 헤더(Header)와 하단 탭바(Tab Bar)를 유지합니다.
상세 화면 진입 시 하단 탭바는 숨김 처리되고, 헤더에 뒤로가기 버튼이 노출됩니다.

2.2 UI Component Policy (UI 정책)

모든 UI 컴포넌트는 사내 디자인 표준 시스템인 ui.doksam.com의 profile-data 프로필을 따릅니다.
- 포인트 컬러: Violet (다크 모드 베이스)
- 주요 버튼: Kebab Menu, Tooltip Icon Button 적용
