`doksam-ui` Skill 을 작업 계약의 단일 원본으로 사용한다.

ui.doksam.com 이 디자인 표준의 SSOT 다 — 작업 시작 시 /llms.txt 로 카탈로그를
live 확인하고, 브랜드 프로필 확정 → 레지스트리 설치(재발명 금지) → 규칙 준수
구현 순서를 따른다. 규칙 세부는 Skill 에 있는 것을 따르고, 이 파일에 복제하지
않는다.

표준 준수 체크리스트 전 항목을 확인한 결과와 함께 산출물을 전달한다.
