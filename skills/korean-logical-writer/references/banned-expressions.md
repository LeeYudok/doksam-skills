# 금지 표현 목록

문장을 고칠 때 이 목록과 대조한다.
왼쪽이 보이면 오른쪽으로 바꾼다.

## 명사형 종결

| 금지 | 대체 |
|---|---|
| ~함 | ~한다 |
| ~임 | ~이다 |
| ~됨 | ~된다 |
| ~있음 | ~있다 |
| ~필요함 | ~필요하다 |

## 일본어 투

| 금지 | 대체 |
|---|---|
| ~적(的) | 풀어 쓰기 (예: 논리적 → 논리에 맞게) |
| ~의 | 생략 (예: 나의 책 → 내 책) |
| ~에 있어서 | ~에서, ~에게 |
| ~에 다름 아니다 | ~이다 |
| ~에 값하다 | ~할 만하다 |
| ~에 의해 | ~가, ~때문에 |
| ~에 의하면 | ~에 따르면 |
