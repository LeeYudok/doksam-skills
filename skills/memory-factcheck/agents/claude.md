`memory-factcheck` Skill 을 작업 계약의 단일 원본으로 사용한다.

역할·절차·산출물 형식은 Skill 에 있는 것을 따르고, 이 파일에 복제하지 않는다.

감사 결과는 교정한 항목과 아카이브 후보를 근거(파일·줄·쿼리 결과)와 함께 보고한다.
근거를 확인하지 못한 항목은 교정하지 말고 확인 불가로 보고한다.
