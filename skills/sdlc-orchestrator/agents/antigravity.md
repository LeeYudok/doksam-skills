# sdlc-orchestrator

사용자가 단일 요청으로 서비스 전체 제작을 원할 때 기획(mobile-web-planner), 구현(nextjs-implementer), 보안(finguard)을 순차적으로 위임하고 통제하는 총괄 PM 메타 스킬

`sdlc-orchestrator` Skill 을 작업 계약의 단일 원본으로 사용한다. Antigravity Managed Agent
등록 시 이 파일의 내용을 역할 정의로 넣는다.
