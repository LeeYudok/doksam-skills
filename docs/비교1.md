  Claude가 1위인 이유:

- 배지 43개로 목업 설명이 충분히 촘촘함
- 컴포넌트 명세 <code>가 80개로 가장 풍부함
- 빈 상태, 마감, 권한, 네트워크 오류, 예약 충돌 등 예외·상태 명세가 가장 구체적
- 게시판 댓글 입력, 투표 집계, 코트 시간대 상태, 회원 개인정보 정책까지 개발 가능한 수준으로 정의
- 접근성, 포커스 트랩, 색상 외 텍스트 병기 등 공통 규칙이 가장 완성도 높음
- HTML에 눈에 띄는 문법 오염이 없음

  Codex 버전은 화면 설계 범위가 가장 넓습니다. 45개 배지와 13개 화면 ID를 사용하고, 특히 게시판의 목록·상세·글쓰기 검증 실패까지 3개 목업으로 보여주는 점은 Claude보다 좋
  습니다. 다만 컴포넌트 명칭과 세부 동작 명세가 Claude보다 적고, 일부 & 문자가 이스케이프되지 않은 경미한 HTML 경고가 있습니다.

  AGY 버전은 시각적 아이콘과 팝업 표현은 적극적이지만 다음 문제가 큽니다.

- 배지가 18개뿐이라 상세 설명 밀도가 낮음
- <code> 컴포넌트 명세가 8개뿐임
- \\n 문자열 57개가 실제 HTML에 들어 있음
- 중복 style 속성 12건
- 기본 버전 규칙은 1.0.0인데 임의로 3.0.0 사용
- 게시판 상세, 공지 상세, 입상 상세 대신 간단한 팝업 위주라 핵심 User Flow가 얕음

  결론적으로 Claude 파일을 최종본 기반으로 사용하고, Codex 파일의 ‘게시글 작성·검증 실패 화면’을 이식하면 세 결과 중 가장 좋은 통합본이 됩니다. 시각 렌더링 환경은 연결되
  지 않아 이번 평가는 구조·마크업·UX 명세 기준입니다.
